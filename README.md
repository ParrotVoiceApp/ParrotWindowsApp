# Parrot Windows App

Parrot Windows App covers the Parrot desktop experience on Windows.

## Scope

- Installation, setup and updates.
- Device connections and desktop calling.
- Windows compatibility and usability.

## Current status

This repository provides public issue tracking and product planning. Product source code is not currently published here.
